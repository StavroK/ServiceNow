# Business Case

## Problem statement

Service-desk triage can become a bottleneck when incident descriptions are inconsistent and assignment depends on analyst interpretation. The result may include delayed ownership, reassignment, inconsistent categorization, and avoidable analyst effort.

## Value hypothesis

AI-assisted triage can create value when it improves decisions without adding unacceptable operational risk.

Expected value levers:

- faster time to assignment;
- fewer reassigned incidents;
- more consistent taxonomy;
- reduced repetitive triage effort;
- faster access to relevant knowledge;
- higher-quality operational data for problem management and service improvement.

## KPI tree

### Adoption
- recommendation coverage;
- analyst acceptance rate;
- percentage of incidents processed by AI.

### Quality
- category accuracy;
- assignment-group accuracy;
- calibration / confidence quality;
- human override rate.

### Operations
- mean time to assign;
- reassignment rate;
- MTTR;
- SLA attainment.

### Economics
- analyst minutes saved;
- avoided rework;
- infrastructure/model cost per incident;
- cost per accepted recommendation.

## Business-case discipline

Targets should not be invented from benchmarks. A production initiative should establish a baseline from the organization's own ServiceNow data, define a counterfactual, pilot with controlled scope, and quantify value after implementation.
